# Object-oriented Python

Classes you write yourself, then a class from a package (`PrettyTable`).

## What I learned

- PascalCase class names
- `__init__` to set attributes when an object is created
- methods that change more than one object (`follow`)
- importing a class and calling methods (`add_row`, `align`)

## Programs

1. **user_class.py** — `User` with id, username, follower/following, and `follow()`.
2. **prettytable_demo.py** — print a left-aligned table. Needs `prettytable` (`pip install -r requirements.txt` from the repo root).

Turtle graphics used to live next to these files; they now live in `05_turtle_graphics`.

## After this folder

You should be able to explain: object, attribute, method, and why `__init__` exists.

## How to run

```
python user_class.py
python prettytable_demo.py
```

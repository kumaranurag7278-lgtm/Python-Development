# Beginner Python

First programs: user input, numbers, strings, if/else, lists, and `random`.

## What I learned

- `input()`, `int()`, `float()`, `round()`, `//`
- f-strings
- `if` / `elif` / `else` and nested choices
- lists and `random.choice` / `randint`
- `for` loops and building a string from a list

## Programs

1. **tip_calculator.py** — bill, tip percent, split between people.
2. **number_manipulation.py** — truncation vs floor division, `+=`, weeks until age 90.
3. **f_strings_and_types.py** — mix text and variables; older name-length / BMI notes in comments.
4. **treasure_island.py** — nested if/else adventure (left/wait/yellow wins).
5. **randomisation_and_lists.py** — lists + random; heads/tails and nested lists in comments. Rock-paper-scissors was not finished.
6. **password_generator.py** — letters, digits, symbols, then shuffle.
7. **letter_guess.py** — guess letters of `"pasta"` one at a time.

## After this folder

You should be able to take input, branch on answers, and loop over a list without looking up every line.

## How to run

```
python tip_calculator.py
python treasure_island.py
python password_generator.py
```

Run from `01_beginner` or from the repo root with `python 01_beginner/...`.
